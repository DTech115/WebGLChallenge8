# WEBGLWeekly8

## Reflection

1. Which textures did you choose & why?  
I tried aiming for more realistically-colored textures that all fit the same palette.
2. How did normal maps improve your scene?  
They added SO much definition to the textures so that they weren't just flat. The walls, gate, & crates all stuck out much more.
3. Which object benefited the most from texture mapping?  
It's between the walls, crates, metal, & floor.
4. What effect did roughness maps have on lighting?  
In the case of the metal, roughness made them darker & less flat.
5. Did texture tiling improve or hurt realism?  
Definitely improve as no tiling made the bricks massive & the ground pebbles HUGE.
6. If you had more time, what additional textures would you add?  
I'd give the battlements their own texture & perhaps add symbols to the banners too.
